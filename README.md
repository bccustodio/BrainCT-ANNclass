# BrainCT-ANNclass
Avaliação de redes neurais artificiais (CNN e MLP-Mixer) na classificação de imagens de CT (normal vs. hemorragia).

Testamos o desempenho de dois tipos de redes neurais artificiais na tarefa de classificação de imagens de CT. O recorte específico da tarefa é para detecção de hemorragia intracraniana, que se manifesta tipicamente como região hiperdensa na fase aguda no exame. Além de ser visualmente interpretável, isso configura um padrão que pode ser extraído e aprendido também por um algoritmo de rede neural.

Em primeiro momento, avaliamos o desempenho em um pequeno banco de dados, algo que naturalmente ocasiona dificuldade de generalização para esse tipo de algoritmos, que exigem um grande número de amostras para extrair padrões e assim conseguir fazer predições com um bom nível de acurácia. 

De modo geral, os resultados são promissores e são de grande valia para entender a configuração de arquiteturas de redes neurais e seus hiperparâmetros. Espera-se expandir os modelos para um banco de dados maior e obter resultados mais confiáveis e reprodutíveis.
